Run A · Cloud free-tier + 1 local

Run A

4 models (2 usable) · 12 questions · ⚠️ Partial

1 · What we set out to test

The first experiment used a vendor-diverse pool of free models — one local (Meta llama3-8b via Ollama) and three OpenRouter :free models (OpenAI gpt-oss-20b, Google gemma-4-31b, NVIDIA nemotron-nano-9b). The goal was simply to get CoEval running end-to-end on cybersecurity and obtain a first ranking.

2 · Results

Of 384 judgments, 194 were valid (51%); two students completed enough to be ranked:

#ModelVendorScore
🥇gpt-oss-20bOpenAI0.919
🥈llama3-8bMeta0.775
Judge bias, first sighting: gpt-oss was a harsh judge (0.26 gap between the two students) while llama3 was lenient (0.02 gap) — the same answers scored very differently depending on who judged.

5 · Conclusions

Did it succeed? Partial success. The methodology worked end-to-end and produced a valid 2-model ranking, but the run did not complete for all models.

Why? Not an algorithmic failure — OpenRouter's free tier enforces an account-wide cap of 50 requests/day and 16/minute, shared across all free models. A full run needs ~1,000 calls, so the cloud students were rate-limited out.

What we concluded & did next: free cloud tiers cannot sustain ensemble evaluation at scale → we moved to fully-local inference (Ollama) for Run B, and switched to an explicit rubric because the small models could not reliably emit the JSON that automatic provisioning requires.
